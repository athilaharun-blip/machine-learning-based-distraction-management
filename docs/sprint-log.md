During this sprint, the project problem statement, requirements, user stories, and specialized technology documentation were prepared. The README was also updated to include the project overview, objectives, documentation links, project structure, and roadmap.

The documentation describes a proposed supervised machine learning system that classifies study sessions into Focused, Distracted, or Highly Distracted based on manually entered study-context information.

### Sprint Retrospective

**What went well:**

- The project documentation was organised into separate Markdown files.
- The functional requirements and user stories were made more specific and testable.
- The proposed machine learning workflow became clearer.

**What was difficult:**

- Deciding how study-context information should be collected.

- Defining attention-state classification without claiming to measure attention directly.

**What I will change next time:**

- Plan the dataset collection and labelling method before developing the machine learning model.
