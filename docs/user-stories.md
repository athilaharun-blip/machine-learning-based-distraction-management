# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

## User Story 1

As a student, I want to provide information about my current context, so that the system can understand my situation. **(FR1)**

### Acceptance Criteria

- The student can provide the required context information.
- The system accepts the provided context information.

## User Story 2

As a student, I want the system to classify my attention state, so that I can understand my current focus level. **(FR2)**

### Acceptance Criteria

- The system classifies the student's attention state using the machine learning model.
- The system provides an attention state classification result.

## User Story 3

As a student, I want to receive digital distraction management support based on my attention state and context, so that I can maintain better focus. **(FR5)**

### Acceptance Criteria

- The system provides suitable support based on the student's context and attention state.
- The student can view the provided digital distraction management support.
